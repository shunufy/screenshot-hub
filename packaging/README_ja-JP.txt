スクリーンショット・ハブ 0.2.0（日本語版）

1. ScreenshotHub.exe をダブルクリックします。
2. 起動後、自動で標準のゲーム／スクリーンショット保存先を探します。
3. Steam、Epic Games、HoYoPlay、Windowsのインストール情報からゲームを見つけ、
   ScreenShot、Screenshots、PhotoMode などのフォルダーを自動検出します。
4. ランチャーに登録されない個人整理フォルダーは「フォルダーを追加」から指定できます。

PCやドライブ全体の無制限な走査は行いません。
Screenshot Hub自身はプレビュー作成時に画像を書き換えず、移動・改名・編集・削除・アップロードを行いません。
設定は %LOCALAPPDATA%\ScreenshotHub\settings.json に保存されます。

対応形式: PNG / JPEG / BMP / GIF / TIFF
動作環境: Windows 10/11 x64

この実行ファイルは未署名です。配布元とRelease NotesのSHA-256を確認してください。
