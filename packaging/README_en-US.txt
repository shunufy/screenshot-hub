Screenshot Hub 1.1.0 (English)

1. Double-click ScreenshotHub.exe.
2. On the first launch only, the app performs a full scan of standard game and screenshot locations.
   Later launches load the saved local catalogs. Use Rescan when you want to update them.
   Scheduled rescanning is available as an opt-in setting and is off by default.
3. It uses Steam, Epic Games, HoYoPlay, and Windows installation information to find games,
   then detects folders such as ScreenShot, Screenshots, and PhotoMode.
4. Use Add folder for personal folders that are not registered by a launcher.
5. Lightweight folder view loads only the saved folder summaries and does not load thumbnails.
6. Favorites, tags, search/filter controls, and a built-in viewer are available in the gallery.
7. Exact-copy and visually-similar analysis runs only when you select Analyze duplicates.
   Results organize the view only; image files are never deleted or consolidated.
8. Saved date filters by today, last 7 days, last 30 days, or a custom range.
   Dates use the file's local last-modified date. Both endpoints are included; either can be blank.
   Clear dates restores all dates. Combine dates with search, tags, and favorites.
9. Sort by newest, oldest, filename, or largest file. Viewer navigation follows this order.
   Duplicate views sort within each group. Date and sort preferences are saved.
   These controls do not trigger additional scanning or image analysis.

Screenshot Hub does not perform an unrestricted scan of your PC or entire drives.
Screenshot Hub does not modify images while creating previews and does not move, rename, edit, delete, or upload them.
Settings are stored at %LOCALAPPDATA%\ScreenshotHub\settings.json.
The full image list and folder summaries are stored locally beside it as
catalog-v1-en-US.json and folders-v1-en-US.json. They are never uploaded.
Favorites/tags are stored in user-data-v1.json and analysis results in analysis-v1.json.

Formats: PNG / JPEG / BMP / GIF / TIFF
System: Windows 10/11 x64
